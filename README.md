# 🎬 CineRental

A modern movie browsing app built with **Next.js 14 App Router**, featuring a cinematic dark UI, multilingual support, and live data from the TMDB API.

---

## ✨ Features

- 🎥 Browse movies by category — Trending, New Releases, Coming Soon, Top Rated, Popular
- 🌐 Bilingual support — English and Bangla (i18n via dynamic `[lang]` routing)
- 🔍 Movie detail modal with hero banner, stats, and stream/download actions
- 📱 Fully responsive — mobile drawer menu + desktop sidebar
- ⚡ Server components with 1-hour ISR caching on all TMDB fetches
- 🎨 Cinematic dark luxury design — Playfair Display + DM Sans, amber/gold accents

---
